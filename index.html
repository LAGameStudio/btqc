Rules Notes

  • Sources: Campaign Operations, Mercenaries, Hinterlands, Draconis Combine campaign books. OpFor & objective modifiers are transparent in Pre-Drop.
  • BV skill multiplier uses Classic table (4/5 = 1.00). PV skill uses AS Companion p.92 (+1 skill ≈ +~10%).
  • Monthly upkeep = 4% of active 'Mech C-Bill value + 15,000 per active MechWarrior + 25,000 Dropship berth.
  • Sheets export: CSV with Forces / Objectives / Payouts / Map — import via File → Import in Google Sheets.
  • Game dates carry their own TW/AS mode switch — Pre-Drop and Export follow the active scenario's date.
  • Outcomes tab: commit a game's result (payouts, repair, salvage, pilot fates) to a brigade's accounting; editing or deleting reverses the old application.
  • Mech icons show battlefield role: 👊 Brawler, 🪓 Striker, 🔭 Scout, 🚀 Missile Boat, 🎯 Sniper, ⚔️ Skirmisher, 🛡️ Juggernaut, 🥷 Ambusher, 🔥 Fire Support. Units with no listed role fall back to a weight-class icon.
