Mech Quick-Add Reference (BV/PV/C-Bills)

Rules Notes

  • Sources: Campaign Operations, Mercenaries, Hinterlands, Draconis Combine campaign books. OpFor & objective modifiers are transparent in Pre-Drop.
  • BV skill multiplier uses Classic table (4/5 = 1.00). PV skill uses AS Companion p.92 (+1 skill ≈ +~10%).
  • Monthly upkeep = 10,000 per 4-mech block in depot (rounded up: 1-4 mechs = 1 block) + combined pilot salaries (1,500 x skill multiplier, see Roster $/Month) + 20,000 Dropship (flight crew 10 x 1,000 + fuel & fees 10,000).
  • Sheets export: ODS workbook with Forces / Objectives / Map sheets — opens in LibreOffice or Google Sheets (File → Import).
  • Game dates carry their own TW/AS mode switch (the recorded ruleset). Pre-Drop always follows the top-bar mode switch; Export follows the scenario's date.
  • New and imported pilots start with 1 XP (Mechwarrior Training).
  • Generated contracts brief each side's entry, placement and role; about 1 in 7 carries a mission quirk from the Strike Brigades tables (see source/Strike_Brigades.md).
  • Surviving deployed pilots earn +1 XP per committed contract (shown in the Roster; click the lock to edit a pilot's XP).
  • Roster Hits shows each pilot's hits from the last contract; over 2 hits puts them in medbay (unavailable next mission, cleared from load slots).
  • Salvage rights split per side on Scenarios › Review (each side's brigades share 100%; a lone brigade takes 100% if victorious; Raider 'To the Victor Goes the Spoils' suspends fixed splits).
  • Outcomes tab: commit a game's result (payouts, salvage, pilot fates) to a brigade's accounting; editing or deleting reverses the old application.
  • Mech icons show battlefield role: 👊 Brawler, 🪓 Striker, 🔭 Scout, 🚀 Missile Boat, 🎯 Sniper, ⚔️ Skirmisher, 🛡️ Juggernaut, 🥷 Ambusher, 🔥 Fire Support. Units with no listed role fall back to a weight-class icon.
